#async-labs-screening - Samarth

Async Labs Internship Screening • Candidate Material

## What I built
I designed and built a polished landing experience for the **Async Labs 7.5" Smart Display** using React + Vite.  
The submission focuses on smooth interactive storytelling, responsive layouts, and a distinctive E-Ink inspired visual system with multiple themes.  
Key decisions prioritized performance, clean component architecture, and usability across desktop and mobile.

## How to view/use it
- **Live Demo:** https://async-labs-screening-samarth.vercel.app/
- **Run locally:**
  1. `git clone https://github.com/Sksamarth/async-labs-screening-Samarth.git`
  2. `cd async-labs-screening-Samarth`
  3. `npm install`
  4. `npm run dev`
