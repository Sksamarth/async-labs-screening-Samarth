## 🚀 1-Click Vercel Deployment Guide

1. Push this repository to GitHub (`async-labs-screening-Samarth`).
2. Open [Vercel Dashboard](https://vercel.com/new) and import the repository.
3. Vercel automatically selects:
   - **Framework:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. Click **Deploy**. Your site goes live in seconds!
